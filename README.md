# 政策通 — 企业政策申报智能匹配平台

> 政策不是玄学，是可拆解的逻辑树。

政策通把模糊的政府政策文件拆解为结构化的**条件逻辑树**，帮助企业快速判断：我符合哪些政策的申报条件、差距在哪里、应该优先申报哪个、怎么准备材料。

## 核心方法论

传统政策咨询的痛点：申报条件散落在数千字的政策原文中，企业不知道自己「差在哪里」。

我的解法 —— **条件逻辑树**：

1. 将每条政策拆成 4-6 个条件大类（基础合规、财务指标、技术能力、环保合规等）
2. 每个大类下拆出 3-8 个具体条件项，标记：是否必选、权重、可否自动判断、佐证材料、政策依据链接
3. 投入企业基本信息 → 自动匹配可判断的条件 → 人工确认需核验的条件 → 生成缺口报告

这本质上是把政策咨询师的专家判断流程，固化为可复用的数据结构和算法。

## 功能一览（5 个标签页）

| 标签页 | 能力 |
|---|---|
| 政策库 | 多维筛选 + 全文搜索（含材料名与佐证文本）、条件树展开（佐证 / 政策依据 / 申报要求 / 官方材料清单）、专精特新梯度全链条、申报窗口时间轴 |
| 智能匹配 | 渐进式问卷（8-12 题收敛、硬淘汰不匹配政策）或完整表单 → 三维评分排序（Fit 50% + Timing 25% + Effort 25%）→ 四档结论 + 信息不足提示 + 近失配恢复兜底 |
| 自诊断 | 单条政策逐条件三态核验（符合 / 不符合 / 不清楚=待核实）→ 诊断报告 → 一键生成**申报作战手册**（缺口清单 + 官方材料清单 + 时间倒推 + 风险点 + 官方链接） |
| 培育规划 | 判断专精特新 5 层梯度层位 → 输出「下一步申报什么 + 差距清单 + 节奏」 |
| 申报路线图 | 1-3 年三层递进规划（近期 0-6 月 / 中期 6-12 月 / 长期 1-3 年）+ 否决区 + 信息不足区 + 材料就绪检查 |

辅助能力：多企业档案（保存 / 切换 / JSON 导入导出 / 诊断历史）、多政策对比（2-3 条并排）、全部报告打印 / 导出 PDF、手机竖屏适配。

## 数据规模与质量

- 当前收录 **30 条政策**（国家级 15 / 广东省 11 / 珠三角地市 4），300+ 结构化条件
- 每条政策附：官方原文与申报通知链接、官方申报材料清单、申报要求提示、逐条件佐证说明与政策依据链接
- **全部人工核源、可溯源**——数据整理以官方文件为准，搜不到的官方信息如实标注，不编造

## 技术栈

- 多文件 HTML + CSS + JavaScript，**无框架、无构建工具、无后端**，双击即用
- 字段注册表单源（新增字段只改一处）；条件模板库（高频条件模板化，DRY 原则）
- 匹配算法：加权评分 + 必选条件一票否决 + 三维加权评分 + 核验进度门槛 + 已核验覆盖不足判「信息不足」+ 全低分时近失配恢复
